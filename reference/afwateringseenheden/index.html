    Afwateringseenheden

    Tools for preparing vector input for afwateringseenheden.

    SubcatchmentResult dataclass

    Files and polygons produced by one subcatchment calculation.

    WatersysteemRasters dataclass

    Paths to the aligned rasters prepared for one spatial square.

    WatersysteemResult dataclass

    Prepared primary hydroobject segments and point-induced connections.

    hydroobject_segmenten contains primary source lines split at internal point locations and subsequently, by the workflow, at the requested maximum length. hydroobject_verbinding contains a directed, minimal connection tree between final segment_id values at each hydrological node. A segment ending at a node is van_segment and a segment starting there is naar_segment. At a node with multiple incoming and outgoing segments, the lexicographically first segment of each direction is the deterministic main route. Connection geometries are always two-dimensional Points at a shared segment endpoint or at the puntobject that connects endpoints of distinct source hydroobjects.

    prepare_watersysteem(hydroobjecten, puntobjecten, *, tolerance=2.0, max_length=500.0, hydroobject_secundair=None)

    Prepare primary hydroobjecten and final segment connections.

    This function only performs geometric and topological preparation. It does not read a GeoPackage, download source data, or write output. Input CRS values are required and are explicitly transformed to settings.crs by the underlying geometry helpers. Hydroobjecten are split first at nearby pointobjects and then into segments no longer than max_length.

    Parameters:

    Name Type Description Default
    hydroobjecten GeoDataFrame

    Primary HyDAMO LineString or MultiLineString features. A missing bron_id is safely derived from globalid, code, or index.

    		 required
    puntobjecten GeoDataFrame

    Point features that may split or connect primary hydroobjecten. Relevant point fields are retained on resulting connection records where a point causes a cross-source connection.

    		 required
    tolerance float

    Maximum point-to-line distance in project-CRS units. Must be at least zero.

    		 2.0
    max_length float

    Maximum resulting hydroobject segment length in project-CRS units. Must be greater than zero.

    		 500.0
    hydroobject_secundair GeoDataFrame

    Retained for backwards compatibility. Secondary objects are classified from their full geometry while writing and are not included in primary segment connections.

    		 None

    Returns:

    Type Description
    WatersysteemResult

    hydroobject_segmenten contains stable bron_id and segment_id values. hydroobject_verbinding contains deterministic directed relations between final segment IDs, their source bron_id values, and relevant point attributes.

    prepare_watersysteem_rasters(ruimtelijk_vierkant, *, burn_depth_m, ahn_vrt_path=None, watersysteem_path=None, output_dir=None, data_store=None, resolution_m=2.0, overwrite=False)

    Create aligned DEM and hydroobject-segment rasters for one spatial square.

    The AHN dtm_05 VRT is resampled to a 2 by 2 metre grid by default. Missing elevation cells are filled with rasterio.fill.fillnodata using a search distance spanning the full raster, so the final DEM has no NoData holes. Primary and secondary hydroobjects are rasterized separately. The primary mask has priority, so its two-times burn depth is not added to the one-times secondary depth in overlapping cells. The companion segment raster stores GeoPackage feature IDs, with zero denoting no segment.

    Parameters:

    Name Type Description Default
    ruimtelijk_vierkant BaseGeometry

    Square output extent in :data:waterlagen.settings.settings.crs. Its width and height must be equal and exactly divisible by resolution_m.

    		 required
    burn_depth_m float

    Physical burn depth in metres. Primary hydroobjects are lowered by two times this value and secondary hydroobjects by one times this value.

    		 required
    ahn_vrt_path Path

    AHN source VRT. Defaults to datastore.ahn_dir / 'dtm_05' / 'dtm_05.vrt'.

    		 None
    watersysteem_path Path

    GeoPackage containing hydroobject_primair, hydroobject_secundair, and hydroobject_segment. Defaults to datastore.afwateringseenheden_path / 'watersysteem.gpkg'.

    		 None
    output_dir Path

    Directory for dem_2m.tif and hydroobject_segment.tif. Defaults to datastore.afwateringseenheden_path / 'rasters'.

    		 None
    data_store DataStore

    Datastore used for all default paths.

    		 None
    resolution_m float

    Cell size in project-CRS metres, by default 2.

    		 2.0
    overwrite bool

    Whether existing validated raster pairs are regenerated. With False, both existing valid outputs are reused.

    		 False

    Returns:

    Type Description
    WatersysteemRasters

    Paths to the validated DEM and hydroobject-segment GeoTIFFs.
    Side Effects

    Writes both GeoTIFFs through temporary files beside their targets. Each completed temporary raster is validated before it atomically replaces its corresponding target.

    read_hydroobjecten(hydamo_path, *, spatial_selection=None, waterbeheercodes=None, attribute_filters=None, spatial_selection_crs=settings.crs)

    Read selected HyDAMO hydroobjecten as project-CRS line features.

    MultiLineStrings are exploded while preserving relevant source attributes. Their parts receive a deterministic :0001-style suffix on bron_id so every returned line can be handled independently. Empty, invalid, and non-line geometries are skipped with a warning. Other returned features use globalid for bron_id where available, otherwise code or the source row index.

    		 required
    spatial_selection BaseGeometry

    Selection geometry in spatial_selection_crs. None reads the complete source layer.

    		 None
    waterbeheercodes Iterable[str | int | float | None]

    Optional codes parsed from the source nen3610id field.

    		 None
    attribute_filters Mapping[str, Collection[object]]

    Exact source-value filters. The documented alias categorieoppervlaktewater maps to the actual HyDAMO column categorieoppwaterlichaam.

    		 None
    spatial_selection_crs str | int

    CRS of spatial_selection. Results always use settings.crs.

    		 crs

    Returns:

    Type Description
    GeoDataFrame

    Selected LineString features with source attributes, bron_id, and normalized waterbeheercode in the configured project CRS.

    split_connected_secondary_hydroobjecten(hydroobject_secundair, hydroobject_primair, hydroobject_verbinding, *, tolerance=2.0)

    Split secondary hydroobjecten into connected and unconnected sources.

    Secondary hydroobjecten form spatially connected components. A component is connected only when at least one member lies within tolerance of a primary hydroobject; a component consisting solely of secondary objects is unconnected. Comparisons include vertices and every position along a line segment, so they do not depend on endpoint-based hydroobject_verbinding records. Those records are retained as an argument for API compatibility and are inspected only to warn about unknown source identifiers.

    Parameters:

    Name Type Description Default
    hydroobject_secundair GeoDataFrame

    Original selected secondary hydroobjecten with unique, non-empty bron_id values.

    		 required
    hydroobject_primair GeoDataFrame

    Original selected primary hydroobjecten with unique, non-empty bron_id values.

    		 required
    hydroobject_verbinding GeoDataFrame

    Existing directed connection layer. It does not determine the spatial classification.

    		 required
    tolerance float

    Maximum distance in metres in the configured project CRS, by default 2. Must be at least zero.

    		 2.0

    Returns:

    Type Description
    tuple[GeoDataFrame, GeoDataFrame]

    Connected secondary hydroobjecten followed by unconnected secondary hydroobjecten. Both preserve the input schema, order, and CRS.

    Raises:

    Type Description
    ValueError

    If a non-empty source layer has missing or duplicate bron_id values, or tolerance is negative.

    split_hydroobjecten_at_points(hydroobjecten, puntobjecten, *, tolerance)

    Split hydroobjecten at nearby points and derive inter-line connections.

    A point is projected to each LineString at distance no greater than tolerance. Internal, unique projected positions split the source line. Endpoint positions are intentionally not split. Connections are derived after the final length segmentation, because only then every connection can refer to final segment_id values.

    Parameters:

    Name Type Description Default
    hydroobjecten GeoDataFrame

    LineString or MultiLineString source features. Missing source IDs are derived safely from globalid, code, or the row index.

    		 required
    puntobjecten GeoDataFrame

    Point source features. Relevant point attributes are copied to derived connection records.

    		 required
    tolerance float

    Maximum projected point-to-line distance in project-CRS units.

    		 required

    Returns:

    Type Description
    WatersysteemResult

    Split source lines and deterministic point-induced connections, both in settings.crs.

    split_hydroobjecten_by_length(hydroobjecten, *, max_length)

    Split lines into equal-length segments no longer than max_length.

    The number of segments is the smallest integer that keeps each segment at or below max_length. The source line length is then divided equally over those segments. Source fields and bron_id are retained. segment_id is based on the source identifier and a deterministic, one-based sequence number.

    write_watersysteem(*, hydroobject_primair, hydroobject_secundair, watersysteem, data_store=None, output_path=None, overwrite=False, secondary_connection_tolerance=2.0)

    Atomically write the prepared watersysteem layers to a GeoPackage.

    Existing output is reused only when it passes the required GeoPackage, layer, and CRS validation. A failed write or validation removes its temporary file and leaves an existing target untouched. Layers with a bundled QML style register that style in the GeoPackage automatically.

    Parameters:

    Name Type Description Default
    hydroobject_primair GeoDataFrame

    Selected primary source hydroobjecten. Written without topology changes.

    		 required
    hydroobject_secundair GeoDataFrame

    Selected secondary source hydroobjecten. They are divided into connected and unconnected output layers using their complete line geometry.

    		 required
    watersysteem WatersysteemResult

    Geometrically prepared primary segments and point-induced connections.

    		 required
    data_store DataStore

    Supplies the default output directory.

    		 None
    output_path Path

    Override for the target GeoPackage. Defaults to datastore.afwateringseenheden_path / 'watersysteem.gpkg'.

    		 None
    overwrite bool

    Whether to replace an existing valid GeoPackage. With False, a valid target is reused; an invalid target is replaced only after a new temporary GeoPackage has been validated.

    		 False
    secondary_connection_tolerance float

    Maximum distance in metres between complete primary and secondary hydroobject geometries when classifying connected secondary objects, by default 2.

    		 2.0

    Returns:

    Type Description
    Path

    Validated GeoPackage with exactly the required output layers.
