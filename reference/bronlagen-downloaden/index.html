    Bronlagen downloaden met Python

    Elk voorbeeld is een zelfstandig script. Volg eerst Aan de slag voor installatie, de opslagmap en het uitvoeren van een script. Instellingen staan bovenaan: pas de gegevensmap en het hergebruik aan, en bij AHN/BGT ook het gebied, de AHN-versie of de objecttypen. Bestaande bestanden worden zoveel mogelijk hergebruikt. Voor een nieuwe bronversie kan bewust opnieuw downloaden nodig zijn; zie het cachegedrag in de API-referentie.

    Waar een download ruimtelijk kan worden beperkt, gebruiken de voorbeelden Alkmaar-centrum. Landelijke bestanden worden volledig opgehaald: een klein voorbeeldgebied maakt die downloads niet kleiner. Een volledige productie haalt de benodigde bronnen zelf op; het is niet nodig alle onderstaande scripts eerst uit te voeren.

    Rijkswateren

    De volledige handmatig gepubliceerde GeoPackage is ook voor kleine gebieden nodig. Het voorbeeld hergebruikt een geldige lokale bron zonder netwerkverkeer.

    """Download de handmatig gepubliceerde landelijke Rijkswaterenbron."""

from pathlib import Path

from waterlagen.datastore import DataStore

OVERWRITE = False

if __name__ == "__main__":
    store = DataStore(
        data_dir=DATA_DIR,
        source_data_dir=DATA_DIR / "source_data",
        processed_data_dir=DATA_DIR / "processed_data",
    )
    with production_logging():
        path = download_rijkswateren(store.hydamo_dir, overwrite=OVERWRITE)
        print(path)

    AHN

    Download de AHN4-DTM-tegels die Alkmaar-centrum raken, met resolutie 0,5 m. Hele AHN-tegels worden opgehaald; de download is groter dan het voorbeeldgebied. Het resultaat is een VRT met bijbehorende GeoTIFFs.

    Over deze bron · API-referentie

    Download het Python-script.

    """AHN downloaden. Hele AHN-tegels rond Alkmaar-centrum; dit is geen uitsnede van 1 km²."""

from pathlib import Path

from waterlagen.ahn import download_ahn
from waterlagen.areas import NAMED_AREAS
from waterlagen.datastore import DataStore
from waterlagen.logger import production_logging

DATA_DIR = Path("data")  # Pas aan naar een map met voldoende vrije ruimte.
OVERWRITE = False  # True vervangt bestaande bronbestanden.
AREA = "alkmaar_centrum"
AHN_VERSION = 4
MODEL = "dtm"

if __name__ == "__main__":
    store = DataStore(
        data_dir=DATA_DIR,
        source_data_dir=DATA_DIR / "source_data",
        processed_data_dir=DATA_DIR / "processed_data",
    )
    with production_logging():
        result = download_ahn(
            ahn_dir=store.ahn_dir,
            poly_mask=NAMED_AREAS[AREA],
            model=MODEL,
            ahn_version=AHN_VERSION,
            service="ahn_pdok",
            cell_size="05",
            missing_only=not OVERWRITE,
            create_vrt=True,
        )
    print(result)

    BGT

    Vraag voor Alkmaar-centrum de objecttypen waterdeel en pand op. Het resultaat bestaat uit afzonderlijke GeoPackages in een eigen map. Dit is een klein voorbeeld van een BGT-aanvraag; de volledige landgebruikproductie gebruikt een landelijk BGT-bestand met meer objecttypen. Dit voorbeeld vervangt die bron niet.

    Over deze bron · API-referentie

    Download het Python-script.

    """BGT downloaden. Kleine BGT-aanvraag; houd deze apart van de landelijke productiebron."""

from pathlib import Path

from waterlagen.bgt import bgt_custom_download
from waterlagen.areas import NAMED_AREAS
from waterlagen.datastore import DataStore
from waterlagen.logger import production_logging

DATA_DIR = Path("data")  # Pas aan naar een map met voldoende vrije ruimte.
OVERWRITE = False  # True vervangt bestaande bronbestanden.
AREA = "alkmaar_centrum"
FEATURETYPES = ("waterdeel", "pand")

if __name__ == "__main__":
    store = DataStore(
        data_dir=DATA_DIR,
        source_data_dir=DATA_DIR / "source_data",
        processed_data_dir=DATA_DIR / "processed_data",
    )
    with production_logging():
        result = bgt_custom_download(
            download_dir=store.bgt_dir / AREA,
            featuretypes=FEATURETYPES,
            poly_mask=NAMED_AREAS[AREA],
            overwrite=OVERWRITE,
        )
    print(result.download_dir)

    BGT-duikers voorbereiden

    Voor automatische voorbereiding via openbare_bron is dit losse script niet nodig; zie de productiehandleiding.

    Dit script selecteert duikers uit het bestaande data/source_data/bgt/bgt.gpkg. Voer eerst BGT-vlakken voorbereiden uit; de duikers komen uit de laag bgt_kunstwerkdeel, met plus-type = duiker. De oorspronkelijke vlakgeometrieën en attributen blijven behouden, met het oorspronkelijke objectnummer in bron_fid. Deze losse route gebruikt de al voorbereide vlakken en kan eerder weggefilterde lijngeometrieën niet herstellen. De automatische route leest de algemene BGT-conversie.

    Standaard wordt Aa en Maas geselecteerd, inclusief volledige rekentegels van 10 × 10 km en 2 km buffer. De selectie dekt ook de bounds-proef in de productiehandleiding. De uitvoer is data/processed_data/brandlagen/aa_en_maas/bgt_duikers.gpkg, laag bgt_duiker; dit pad sluit aan op de voorbeeld-TOML.

    Pas DATA_DIR, AREA en OUTPUT_SUBDIR aan voor een andere gegevensmap of waterschap. Een ontbrekende waterschapsgrens wordt opgehaald; BGT moet al voorbereid zijn. Een bestaand uitvoerbestand blijft behouden en geeft een melding: kies een nieuwe uitvoermap of zet bewust OVERWRITE = True om het te vervangen. Zie Een script uitvoeren voor starten met Pixi.

    Download het voorbereidingsscript.

    """Selecteer BGT-duikers voor Aa en Maas inclusief rekentegels en buffers."""

from pathlib import Path

from shapely.ops import unary_union

from waterlagen._sources import SourcePreparation
from waterlagen.afwateringseenheden.tiles import (
    _calculation_geometry,
    _tiles_for_gebied,
)
from waterlagen.areas import resolve_area
from waterlagen.bgt.duikers import prepare_bgt_culverts
from waterlagen.datastore import DataStore
from waterlagen.logger import production_logging

DATA_DIR = Path("data")
AREA = "38"  # Waterschap Aa en Maas.
OUTPUT_SUBDIR = Path("brandlagen/aa_en_maas")  # Onder processed_data.
OVERWRITE = False  # True vervangt een eerdere selectie.

if __name__ == "__main__":
    store = DataStore(
        data_dir=DATA_DIR,
        source_data_dir=DATA_DIR / "source_data",
        processed_data_dir=DATA_DIR / "processed_data",
    )
    source = store.bgt_dir / "bgt.gpkg"
    output = store.processed_data_dir / OUTPUT_SUBDIR / "bgt_duikers.gpkg"
    with production_logging():
        if output.exists() and not OVERWRITE:
            raise FileExistsError(
                f"{output} bestaat al. Kies een andere OUTPUT_SUBDIR of zet OVERWRITE = True."
            )
        if not source.is_file():
            raise FileNotFoundError(f"Bereid eerst de BGT-vlakken voor: {source}")
        # Alleen een ontbrekende waterschapsgrens wordt automatisch opgehaald.
        area = resolve_area(AREA, store, SourcePreparation())
        tiles = _tiles_for_gebied(
            area.geometry, tile_size_m=10000, origin_x=0, origin_y=0
        )
        selection = unary_union(
            [_calculation_geometry(tile, tile_buffer_m=2000) for tile in tiles]
        )
        prepare_bgt_culverts(source, output, selection)
    print(output)

    OSM-kanalen

    Download open kanalen, sloten, afvoerwatergangen, beken en duikers voor het ingestelde gebied. Het voorbeeld gebruikt Aa en Maas inclusief tegelbuffers. Onder source_data/osm/ komen vijf bestanden: osm_canals.gpkg, osm_ditches.gpkg, osm_drains.gpkg, osm_streams.gpkg en osm_culverts.gpkg. Pas DATA_DIR en BOUNDS aan voor een ander gebied. Een bestaande download wordt alleen hergebruikt bij dezelfde selectie; kies anders een ander uitvoerpad of zet OVERWRITE = True.

    Over deze bron · API-referentie

    Download het Python-script.

    """OSM-waterlopen en duikers downloaden voor Aa en Maas inclusief tegelbuffers."""

from pathlib import Path

from waterlagen.datastore import DataStore
from waterlagen.logger import production_logging
from waterlagen.osm_waterlopen import (
    download_osm_canals,
    download_osm_culverts,
    download_osm_waterlopen,
)

DATA_DIR = Path("data")  # Pas aan naar de gebruikte datastore.
BOUNDS = (128000, 368000, 212000, 432000)  # EPSG:28992; Aa en Maas met tegelbuffers.
OVERWRITE = False

if __name__ == "__main__":
    store = DataStore(
        data_dir=DATA_DIR,
        source_data_dir=DATA_DIR / "source_data",
        processed_data_dir=DATA_DIR / "processed_data",
    )
    with production_logging():
        result = download_osm_canals(BOUNDS, data_store=store, overwrite=OVERWRITE)
        print(result)
        for waterway in ("ditch", "drain", "stream"):
            result = download_osm_waterlopen(
                BOUNDS, waterway=waterway, data_store=store, overwrite=OVERWRITE
            )
            print(result)
        result = download_osm_culverts(BOUNDS, data_store=store, overwrite=OVERWRITE)
        print(result)
