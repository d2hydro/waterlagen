    Afwateringseenheden

    Produce full tiles with separate drainage targets and surrounding burn context.

    Joint water/culvert raster connectivity is always prepared, including without additional burn sources.

    Parameters:

    Name Type Description Default
    data_store DataStore

    Source and output locations.

    		 None
    area str or Area or ProductionArea

    Input selection; results are not clipped to this boundary. A water authority code also selects that authority's primary drainage targets.

    		 nederland
    workers int

    Override the configured number of processes.

    		 None
    run_id str

    Unique output run, default a UTC timestamp.

    		 None
    resume bool

    Reuse or rebuild a compatible existing run.

    		 False
    overwrite bool

    Reuse or rebuild a compatible existing run.

    		 False
    refresh_sources bool

    Refresh sources for a new run, or require local sources.

    		 False
    offline bool

    Refresh sources for a new run, or require local sources.

    		 False
    preparation SourcePreparation

    Shared source policy for nested productions.

    		 None
    brandlagen BrandlagenConfig

    Optional burn layers. Explicit public sources are prepared for the full calculation context; local user files are never downloaded or replaced. Checked before AHN preparation. Recorded source identities and defaults must match when resuming a run.

    		 None
    overige_waterschappen bool

    Include surrounding water authorities as targets, default False. Requires an authority area. RWS remains burn context when an authority is chosen.

    		 False
    eigen_hydamo Path

    Complete hydroobject/gemaal/stuw/duikersifonhevel replacement for the selected authority. Validated before AHN preparation. Requires an authority area.

    		 None
    rijkswateren_url str

    Published RWS source location. Local sources are reused unless refresh is requested. Without an authority code, RWS also supplies targets.

    		 RIJKSWATEREN_URL
    duiker_tolerance float

    Inclusive maximum endpoint distance to primary lines, default 0.5 m.

    		 0.5
    max_aansluitlengte float

    Maximum direct adjoining length excluded from targets, default None. Does not change primary burning. Finite, non-negative; zero is valid.

    		 None

    Returns:

    Type Description
    Path

    Combined afwateringseenheden GeoPackage.

    Gebieden

    Create a rectangular input selection without performing I/O.

    Parameters:

    Name Type Description Default
    bounds sequence of float

    Four finite coordinates: xmin, ymin, xmax, ymax, in settings.crs. Both maximum coordinates must exceed their minimum.

    		 required

    Returns:

    Type Description
    ProductionArea

    Bbox polygon with a canonical coordinate-based name. The selection does not clip production outputs or change their grids.

    Raises:

    Type Description
    ValueError

    If the coordinates do not describe a finite, nonempty rectangle.

    Resolved input selection in the configured project CRS.

    identity property

    Stable run identity, including the actual boundary and CRS.

    Resolve a shared input selection, preparing its boundary when needed.

    Parameters:

    Name Type Description Default
    area str or Area or ProductionArea

    Named polygon, Nederland, a water authority code, or a rectangle made with area_from_bounds.

    		 required
    store DataStore

    Source cache locations.

    		 required
    preparation SourcePreparation

    Reuse, refresh and offline policy.

    		 required

    Returns:

    Type Description
    ProductionArea

    Nonempty polygon geometry in settings.crs.
