# TOP10NL

## Beschrijving

TOP10NL is de topografische dataset op schaalniveau 1:10.000, onderdeel van de
Basisregistratie Topografie (BRT). Waterlagen leest functionele gebieden uit de
landelijke GeoPackage.

## Leverancier

Kadaster, ontsloten via PDOK.

## Dataset of service

Waterlagen download `top10nl_Compleet.gpkg` uit de PDOK-downloadvoorziening.

## Gebruik in Waterlagen

TOP10NL-functionele gebieden zijn invoer voor
[functioneel landgebruik](../bewerkingen/functioneel-landgebruik.md).
