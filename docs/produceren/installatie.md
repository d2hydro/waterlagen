# Installatie

Waterlagen ondersteunt Python 3.11 en hoger. Installeer de gepubliceerde versie
in uw Python-omgeving met:

```bash
pip install waterlagen
```

Voor ontwikkeling vanuit de repository wordt de omgeving met
[pixi](https://pixi.sh/) beheerd; zie [Ontwikkelomgeving](../bijdragen/ontwikkelomgeving.md).
