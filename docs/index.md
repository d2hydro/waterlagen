# Waterlagen

Waterlagen is een Python-pakket voor het downloaden, verwerken en produceren van gestandaardiseerde GIS-basislagen voor toepassingen in het waterbeheer.

## Achtergrond

Waterlagen maakt gebruik van verschillende [bronlagen](bronlagen/index.md), zoals landelijke basisregistraties, hoogtegegevens en andere openbare datasets.

Waterlagen verwerkt deze brongegevens tot direct bruikbare GIS-lagen. Zie het overzicht van [bewerkte lagen](bewerkte-lagen/index.md).

Voor de nieuwe WaterSchadeSchatter:

- [Auto's (punten)](bewerkte-lagen/autos.md)
- [DEM (WSWO, raster)](bewerkte-lagen/dem.md)
- [Functioneel landgebruik (raster)](bewerkte-lagen/functioneel-landgebruik.md)
- [Inwoners (punten)](bewerkte-lagen/inwoners.md)

Voor hydrologische analyses/modellering:

- [Afwateringseenheden (features)](bewerkte-lagen/afwateringseenheden.md)

## Zelf aan de slag

Begin bij [zelf produceren](produceren/index.md) voor het genereren van lagen met deze module. Voor rechtstreeks gebruik vanuit Python is er de [API-referentie](reference/ahn.md).

## Ontwikkeling

Waterlagen is open source en wordt ontwikkeld door D2Hydro. Wilt u bijdragen aan de ontwikkeling, bekijk dan [Bijdragen](bijdragen/index.md).

Deze module is ontwikkeld met ondersteuning van AI. Lagen, methoden, code en documentatie worden door mensen beoordeeld en gevalideerd. Zie: [AI-gebruik](over/ai-gebruik.md).
