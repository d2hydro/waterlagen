# DGM1 Nordrhein-Westfalen

lokale URL-lijst. De bestanden behouden UTM32/DHHN2016; de omzetting naar RD/NAP
staat bij [`prepare_ahn_dgm1_dem()`](afwateringseenheden.md#waterlagen.afwateringseenheden.dem.prepare_ahn_dgm1_dem).
Zie [DGM1](../bronnen/dgm1.md) voor de bron en
[DGM1 downloaden](../produceren/dgm1.md) voor uitvoervoorbeelden.
